# Site da Laura ❤️

## Como usar

1. Abra `index.html` no navegador.
2. Para colocar fotos, substitua os arquivos:
   - `assets/foto1.jpg`
   - `assets/foto2.jpg`
   - `assets/foto3.jpg`
   - `assets/foto4.jpg`
3. Para colocar uma música, adicione seu arquivo como:
   - `assets/musica.mp3`
4. Abra `script.js` e confira a variável `EXAM_DATE`.
5. Se o horário da prova for diferente, altere essa variável.

## Estrutura

- `index.html` — conteúdo do site
- `style.css` — visual, responsividade e animações
- `script.js` — interações, contador e efeitos
- `assets/` — fotos e música

O site não depende de servidor para funcionar. Basta abrir o `index.html`.

Observação: as fontes do Google Fonts precisam de internet para carregar a tipografia personalizada. Sem internet, o site continua funcionando usando fontes alternativas.
